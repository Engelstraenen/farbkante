# FARBKANTE – Demo-Webseite Maler- und Lackiererbetrieb (fiktiv)

Scrollytelling: Film-Kapitel im Wechsel mit Motion Design (Aufbau wie FLUTLICHT27). Demo von PROJEKT EX.

- Bilder bauen: `python3 tools/assets.py` (Quellen in `assets-roh/4k/`, nicht im Repo)
- Vorschau: `python3 tools/serve.py 4371` → http://localhost:4371/
- Prüfen: `python3 tools/check.py http://localhost:4371/ <ordner> 1440x900 "fassade:0,leistungen:.6"`
